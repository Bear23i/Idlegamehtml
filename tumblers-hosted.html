How to play

Crack the safe using logic alone.

Each dial hides a number. The clues below the safe are all true, and exactly one combination satisfies every one of them — so there is always a path to the answer by pure reasoning. No guessing required.

Use the arrows to set each dial, then hit Crack it. A wrong attempt costs you nothing but a tick on the counter.

Stuck? A hint locks one dial to its correct value. Everyone gets the same daily safe, and your streak grows for each day you crack it.
